Reading the Alderney ferry timetable with JavaScript off

27 November 2026

The saved timetable for Friday, 27 November 2026, showed 06:30 Halifax time as the first scheduled departure from Alderney Landing in Dartmouth to downtown Halifax. For a trip today, check Halifax Transit’s current ferry schedule.

What the browser found

Slow Web opened Halifax Next in a fresh Chromium session with JavaScript disabled. The downloaded page contained both the service date and a clock time for the crossing. You can repeat the check by turning off JavaScript, reloading the Alderney departure page and reading the date next to the time. The 27 November browser receipt preserves the original result as the timetable changes.

What 56 kb/s would buy

Chromium counted 5,558 encoded bytes across two finished responses. Multiply by eight to get 44,464 bits. At an ideal 56,000 bits per second, transferring those bits would take about 0.8 seconds. The check ran through a managed HTTPS proxy. It never dialled a modem or timed a passenger’s wait for the page. A real connection would also spend time reaching the server and setting up the connection. Read the measurement method.

Try a different task at the same landing

The Dartmouth ferry photo record gave the same browser links to the 1950s Portland Street and 1960s Queen Street photographs. On the interactive map, the control for switching to the 2025 satellite layer was unavailable with JavaScript off. A page can make its evidence readable while an interactive control still needs scripting. Compare the photo-link receipt and the map-control receipt.
