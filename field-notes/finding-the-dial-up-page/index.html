Finding the dial-up page

19 November 2026

How did Statistics Canada describe connecting to the internet by telephone? Two issues of The Daily put “dial-up” in different contexts. In 2001 it was the point of comparison for cable access. By 2003 the publication used it to explain the origins of household internet access.

Find the original passages

Search the nine issues for “dial-up”. Open page 2 of July 26, 2001. Under Strong growth in Internet connection by cable, the survey distinguishes cable access from using a telephone line.

Next open page 5 of September 23, 2003. The broadband article looks back at dial-up during the 1990s. Keep the issue date and physical page number together if you cite either account.

Repeat it on Linux

You’ll need Git, Python 3 with SQLite FTS5 support, and Poppler’s pdftotext. If this is your first time using the CoolCode repository, clone it and enter the checkout.

git clone https://github.com/jsdyer/jsdyer.github.io.git
cd jsdyer.github.io

From the repository root, create a temporary directory for the search index, index the nine original PDFs, and run the same search.

work=$(mktemp -d)
tool=tools/archive-shelf/archive_shelf.py
python3 "$tool" index archive-shelf/issues --db "$work/shelf.sqlite"
python3 "$tool" search 'dial-up' --db "$work/shelf.sqlite"

The Linux search returns three physical pages across three issues. The July 2001 result has this filename and page number.

the-daily-2001-07-26.pdf  (page 2)

The third issue in this set is August 15, 2006, page 7, where the survey explains how it defined high-speed access. You can download the search results as JSON to keep all three citations and links.

Try a box of your own

Point the index command at a folder of local minutes or newsletters and use a fresh database path for that collection. For an image-only scan, text extraction can return an empty page. Archive Shelf flags pages with no extractable text so you can decide which scans to OCR and reindex.
