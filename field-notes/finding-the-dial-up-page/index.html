Finding the dial-up page

12 November 2026

What time did the second modem line open? The answer is in the November 1998 issue of the Rainline Community Network Bulletin, a fictional newsletter written for this experiment. Its filename gives you the publication. The interesting detail is one sentence on an inside page.

Go from a word to a page

Search the sample for “dial-up”. The result points to page 2. Open it in the PDF and look under Two lines after dark.

“The second dial-up line opens at seven each evening.”

Now try “tape rotation”. You land on page 3 of the same issue, in The Friday shelf. Both hits would look identical in a list of matching filenames. The page number lets you find the passage again, even in a printed copy.

Repeat it on Linux

You’ll need Git, Python 3 with SQLite FTS5 support, and Poppler’s pdftotext. If this is your first time using the CoolCode repository, clone it and enter the checkout.

git clone https://github.com/jsdyer/jsdyer.github.io.git
cd jsdyer.github.io

From the repository root, create a temporary directory for the search index, index the sample PDF, and run the same search.

work=$(mktemp -d)
tool=tools/archive-shelf/archive_shelf.py
python3 "$tool" index archive-shelf/sample --db "$work/shelf.sqlite"
python3 "$tool" search 'dial-up' --db "$work/shelf.sqlite"

The first two lines of the result show the citation and the surrounding words. Brackets mark the search phrase.

rainline-bulletin.pdf  (page 2)
  … 04 FROM THE EQUIPMENT DESK Two lines after dark The second [dial-up] line opens at seven each evening. The first line stays available …

Check the result against page 2 of the original. In a larger collection, save the filename and page number together when you cite a passage. You can share that reference with another reader even if their collection lives on a different drive.

Try a box of your own

Point the index command at a folder of local minutes or newsletters and use a fresh database path for that collection. For an image-only scan, text extraction can return an empty page. Archive Shelf flags pages with no extractable text so you can decide which scans to OCR and reindex.
