03 / get your hands dirty

Start on Linux.

This whole website is plain HTML and CSS hosted with GitHub Pages. Clone the source, serve it locally, and change whatever you like.

No build chain, dependencies, or deployment platform required for a local preview.

Open the repository ↗

Three commands to start

git clone https://github.com/jsdyer/jsdyer.github.io.git
cd jsdyer.github.io
python3 -m http.server 8000

Then open localhost:8000 in your browser. For LANWatch, see the project instructions.
