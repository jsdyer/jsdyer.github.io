# Archive Shelf

Search a three-page fictional community newsletter and open its original PDF at the matching page. The browser edition runs entirely on the sample included with the site.

<!-- coolcode:guide -->
Try “dial-up” to find the matching newsletter page. The Linux edition can build the same kind of searchable shelf from your own PDFs and text files.
<!-- /coolcode:guide -->

The November 1998 Rainline Community Network Bulletin was created for the demo. Its dates and community are fictional. The example searches pre-extracted page text and opens the matching PDF page. You can also browse all three pages with JavaScript disabled.

The Linux guide covers indexing, searching and maintaining a collection on your own machine. [Linux edition](../tools/archive-shelf/README.md)
