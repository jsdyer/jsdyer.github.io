Site administration

This tab sends your token to the CoolCode collector to verify your GitHub identity. Your read-only token opens reports. For optional write actions, use a fine-grained token that includes jsdyer/jsdyer.github.io: Contents read/write publishes lineups; Actions read/write enables Check GitHub now. The Linux watchdog’s GitHub App is a separate credential. Opening Cloudflare usage also sends the token to CoolCode’s admin metrics Worker for the same owner check. Reading tool outcome reports, publishing, Check GitHub now and optional repository traffic lookups send the token directly to GitHub. Repository traffic requires Administration read access to the selected repository.
