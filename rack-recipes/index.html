Run this recipe

Save compose.yaml in a new folder on a machine with Docker Engine and Compose. Open a terminal there and run

docker compose config --quiet
docker compose up -d

    Open these addresses on the Docker host. Data stays in local named volumes. Run docker compose stop to pause the stack.
