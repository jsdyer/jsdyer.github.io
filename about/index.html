About CoolCode

Jeffrey Dyer builds CoolCode in Canada. The collection grew from questions about places he knows in British Columbia and Nova Scotia. Which way does a crowded Langley bus travel? What did Halifax look like before the Cogswell Interchange? The tools let you explore a question, change the inputs and follow the result back to its source.

Where the figures come from

The catalogue explains what each tool measures. Saved datasets have source and retrieval details where available. Each tool’s guide describes coverage, definitions and known gaps. Some tools work entirely with files or calculations on your device.

Site statistics and feedback

When site statistics are enabled, CoolCode counts tool opens and interactions with featured homepage cards. The counter uses tool names and test lineups. It leaves search terms, uploaded files, precise locations and full page addresses out of the event. The homepage keeps an A/B assignment in the current tab for the duration of a test. The counter respects Global Privacy Control and Do Not Track where browsers expose either setting.

The catalogue, Release Receipt, Policy Rate Scorecard, Export Neighbours, Metro Economy, Pantry Prices, Well Layers and Halifax Time Lens send selected browser errors to Sentry. Each report contains the tool name, a standard error category and a location in a published script. The browser omits messages, search terms, stack text and file contents. Sentry receives standard network information when the browser connects. Up to three distinct errors are sent per page load. Global Privacy Control and Do Not Track also disable these reports.

If something looks wrong, include the tool name and what you expected. Leave sensitive inputs out of your report.
