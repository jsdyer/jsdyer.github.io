# November 2026 tool audit

CoolCode listed 112 tools. The catalogue audit reached all 224 destination, source, installation and data links it checks. All 106 browser entries returned a page. Workflow tests concentrated on the tools below. A successful link check establishes availability at check time. The recorded freshness fields were also read from each tool’s published metadata.

## Research and diagnostics

| Tool | Try this |
| --- | --- |
| [Halifax Time Lens](https://coolcode.ca/halifaxtimelens/#story=cogswell) | Compare Cogswell in the two aerial mosaics, open the associated archival photographs and export your saved map references as GeoJSON. |
| [Weather Archive](https://coolcode.ca/weatherarchive/?a=1104570&b=8202251&from=2024-01-01&through=2025-12-31) | Explore two full years for Langley and Halifax. Choose a month for the daily table and download the full period with ECCC flags. A failed source page blocks partial CSV export. |
| [DNS Lens](https://coolcode.ca/dnslens/) | Check a website and its www name, a mail setup or an exact record. Import an earlier report from the same resolver to see added and removed answers. |
| [Protocol Cabinet](https://coolcode.ca/protocol-cabinet/) | Inspect a live HTTP response, sort your browser HAR by slowest request, inspect a DNS JSON reply, or reconstruct the Received lines in a local email. |
| [Rack Recipes](https://coolcode.ca/rack-recipes/) | Reopen a previous Rack Recipes Compose export, change storage or host ports and download the revised YAML. A duplicate host port is identified before export. |
| [Packet Pocket](https://coolcode.ca/packetpocket/) | Compare two local captures by packet and byte rates. Choose a conversation, inspect both directions and export an aggregate without addresses or payloads. |
| [Prefix Diary](https://coolcode.ca/prefixdiary/ip/) | Check a Canadian IPv4 or IPv6 registration across three ARIN editions. Follow the selected prefix into Route Archaeologist to inspect observed BGP routing. |
| [Pantry Prices](https://coolcode.ca/pantryprices/) | Price a basket in the original 1914–1959 annual collection, the 1960–1970 printed tables or later monthly series. Choose a province where published and download item-level citations. The continuous annual basket stops in 1970. National monthly coverage starts in 1995, and the scanner-price series begins in 2017. A separate Year Book benchmark compares ten matched packages in 1935 and 2008 and records selected milk and egg prices for 1985. |
| [Exploit Graveyard](https://coolcode.ca/exploitgraveyard/?ca=AV25-769) | Open a Canadian notice and inspect its explicit CVE references alongside CISA’s catalogue. The filter describes published advisories. A deployment’s exposure needs independent evidence. |
| [Well Layers](https://coolcode.ca/welllayers/?left=BC-30145&right=NS-000119&units=m&depth=20#depth-probe) | Look 20 m down at two wells, then inspect all sampled logs at that depth. Separate unrecorded material, qualified descriptions and logs that ended above the probe. |
| [Library Workbench](https://coolcode.ca/libraryworkbench/#tape-planner) | Match a tape and video standard to a Vancouver Public Library station and estimate digitizing time and storage. |
| [Shopfront Diary](https://coolcode.ca/shopfrontdiary/#street-comparison) | Compare an address across directory editions. Each reviewed listing links to a scanned page, and the comparison distinguishes a printed vacancy from a gap in the selection. |
| [Clam Grounds](https://coolcode.ca/clamground/#landings) | Compare two landing histories, distinguish withheld values and open the quantity table for ten counties in the 1931 fisheries return. |
| [Atlantic Dial](https://coolcode.ca/atlanticdial/#field-recordings) | Search Nova Scotia Archives recordings by place or performer and open the player at the track’s cue. |
| [Route Mirror](https://coolcode.ca/routemirror/) | See which TransLink routes consistently reverse their busier direction between the morning and afternoon peaks. |
| [Transfer Window](https://coolcode.ca/transferwindow/) | Pick an arrival window at Carvolth and see which scheduled connections survive a longer walk or delayed arrival. |

| [Tracker X-Ray](https://coolcode.ca/trackerxray/) | Inspect a local browser HAR or use the timing records observed by your browser while loading the tool. |
